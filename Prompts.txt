Build Module 6 of Job Bot: scrapers/glassdoor_scraper.py.

This module uses Playwright (async API, Chromium) to scrape job listings from Glassdoor. It must handle being blocked gracefully — if a CAPTCHA or login wall is detected, log it and return whatever results were collected so far rather than crashing.

Implement: async def search(titles: list[str], config: dict, proxy_url: str = None) -> list[Job]

Behavior:
- Launch Playwright Chromium in headless mode. If proxy_url is provided, pass it to the browser launch args.
- Set a realistic user-agent string (current Chrome on Windows 11).
- For each title and each location in config["target_locations"], navigate to: https://www.glassdoor.com/Job/jobs.htm?sc.keyword=[URL-encoded title]&locT=C&locId=1147401 (New York example — map common locations to Glassdoor location IDs in a small lookup dict; for "remote" use &remoteWorkType=1).
- Wait for job cards to appear (selector: [data-test="jobListing"] or similar — check common Glassdoor job card selectors and use the most stable one). Timeout 15 seconds. If timeout, log and continue to next query.
- For each job card visible on the page (limit 20 per query): extract title, employer, location, and the job detail URL. Click the card and wait for the detail panel to load, then extract the full job description text.

- Enforce a randomized 3–6 second delay between card clicks and between search queries.
- Detect CAPTCHA by checking if the page URL contains "captcha" or if a known CAPTCHA element selector is present. If detected, log a warning and break out of the current loop.
- Construct a Job object for each result. id = SHA256(employer.lower() + title.lower() + location.lower()). source = "glassdoor".
- Close the browser and return the results list.
