You are helping build Job Bot, a standalone Windows desktop application written in Python 3.11+. 
It is a fully automated job search and application system. The user is not a programmer — 
the final deliverable must be a single .exe file that a non-technical person can run.
What it does: Job Bot runs on a schedule between 7am and 5pm EST. It scrapes job postings from multiple sources, 
scores each posting against the user's resume using the Anthropic Claude API, generates a tailored 1–2 page resume 
and cover letter for each matching job, and then applies — either by emailing the hiring manager directly, 
auto-filling a company job portal, applying via the job board itself, or emailing the user with the tailored documents
and a link so they can apply manually.

Core principles:

Every module must work on Windows 11. Use pathlib.Path everywhere. Never hardcode forward slashes in file paths.
All user data (config, tokens, resume JSON, application logs) lives in %APPDATA%\JobBot\. The exe itself is stateless.
Graceful degradation is mandatory. If any step fails (scraper blocked, portal CAPTCHA, API error), the system logs the failure and routes to the next best option. It never crashes silently and never skips logging.
The Anthropic API model is always claude-sonnet-4-20250514. Max tokens 1000 unless specified otherwise.
SQLite is the only database. No ORM — use raw sqlite3.
Playwright is used for all browser automation. Browser is Chromium only.
Rate limiting is built into every scraper. Minimum 3–5 second randomized delay between requests.
Proxies are optional. If proxy_list in config is non-empty, scrapers rotate through them round-robin.
Tech stack:
