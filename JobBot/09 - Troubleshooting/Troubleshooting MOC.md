# Troubleshooting MOC

Something isn't working? Start here.

> [!tip] First step: check the log
> Open `%APPDATA%\JobBot\logs\jobbot.log` — it has timestamped entries for everything that happened. Paste the last few lines into a search engine or ask for help with the specific error message.
